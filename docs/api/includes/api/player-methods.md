<details><summary>play()</summary>
<div>
<br/>

开始播放动画，已暂停时从当前位置继续

返回：

* `Player` this

</div>
</details>

<details><summary>pause()</summary>
<div>
<br/>

暂停动画播放，可再用 play 继续

返回：

* `Player` this

</div>
</details>

<details><summary>cancel()</summary>
<div>
<br/>

取消动画并回到可重新播放的初始状态

返回：

* `Player` this

</div>
</details>

<details><summary>finish()</summary>
<div>
<br/>

结束动画播放，之后不能再播放

返回：

* `Player` this

</div>
</details>

<details><summary>reverse()</summary>
<div>
<br/>

反转动画播放，源码中为空实现

</div>
</details>
