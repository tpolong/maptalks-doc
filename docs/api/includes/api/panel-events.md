<details><summary>contentchange</summary>
<div>
<br/>

panel 内容被重新设置时触发

参数属性：

| 属性名 | 类型 | 值 |
| --- | :-: | --- |
| type | `String` | contentchange |
| target | `control.Panel` | Panel |
| old | `String|HTMLElement` | old content |
| new | `String|HTMLElement` | new content |

</div>
</details>

<details><summary>dragstart</summary>
<div>
<br/>

开始拖动 panel 时触发

参数属性：

| 属性名 | 类型 | 值 |
| --- | :-: | --- |
| type | `String` | dragstart |
| target | `UIMarker` | the panel control fires event |
| mousePos | `Point` | mouse position |
| domEvent | `Event` | dom event |

</div>
</details>
