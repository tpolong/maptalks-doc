<div>
<br/>

| 属性名 | 类型 | 值 |
| --- | :-: | --- |

| target | `UIMarker` | the uimarker fires event |
| coordinate | `Coordinate` | coordinate of the event |
| containerPoint | `Point` | container point of the event |
| viewPoint | `Point` | view point of the event |
| domEvent | `Event` | dom event |
