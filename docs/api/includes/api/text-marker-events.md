<details><summary>edittextstart</summary>
<div>
<br/>

TextMarker 开始编辑文本内容时触发

参数属性：

| 属性名 | 类型 | 值 |
| --- | :-: | --- |
| type | `String` | edittextstart |
| target | `TextMarker` | fires the event |

</div>
</details>

<details><summary>edittextend</summary>
<div>
<br/>

TextMarker 结束编辑并保存文本后触发

参数属性：

| 属性名 | 类型 | 值 |
| --- | :-: | --- |
| type | `String` | edittextend |
| target | `TextMarker` | textMarker fires the event |

</div>
</details>
