<details><summary>positionchange</summary>
<div>
<br/>

Fired after the control position is updated.

Event properties:

| Property | Type | Value |
| --- | :-: | --- |
| type | `String` | positionchange |
| target | `control.Control` | the control instance |
| position | `Object` | Position of the control, eg:&#123;"top" : 100, "left" : 50&#125; |

</div>
</details>
