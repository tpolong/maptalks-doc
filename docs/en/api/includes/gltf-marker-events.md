<details><summary>add</summary>
<div>
<br/>

Fired when the GLTFMarker is added to a layer.

Event properties:

| Property           |   Type           |   Value |
|  ------         | :----:  | ----  |
|type     | String          |   "add"  |
|target   | GLTFMarker      |   this            |
|layer    | GLTFLayer       |   The GLTF layer        |

</div>
</details>
