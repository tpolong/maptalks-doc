* For vector tile data, Features with a type of Point, LineString, Polygon, MultiPoint, MultiLineString or MultiPolygon are supported
* For GeoJSON data, Features with a type of Point, LineString, Polygon, MultiPoint, MultiLineString or MultiPolygon are supported
* For vector layers, [maptalks.Marker](https://maptalks.org/maptalks.js/api/0.x/Marker.html), [maptalks.MultiPoint](https://maptalks.org/maptalks.js/api/0.x/MultiPoint.html), [maptalks.LineString](https://maptalks.org/maptalks.js/api/0.x/LineString.html), [maptalks.MultiLineString](https://maptalks.org/maptalks.js/api/0.x/MultiLineString.html), [maptalks.Polygon](https://maptalks.org/maptalks.js/api/0.x/Polygon.html), [maptalks.MultiPolygon](https://maptalks.org/maptalks.js/api/0.x/MultiPolygon.html) are supported.
