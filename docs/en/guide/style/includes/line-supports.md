* For vector tile data, Features with a type of LineString, Polygon, MultiLineString or MultiPolygon are supported
* For GeoJSON data, Features with a type of LineString, Polygon, MultiLineString or MultiPolygon are supported
* For vector layers, [maptalks.LineString](https://maptalks.org/maptalks.js/api/0.x/LineString.html), [maptalks.MultiLineString](https://maptalks.org/maptalks.js/api/0.x/MultiLineString.html), [maptalks.Polygon](https://maptalks.org/maptalks.js/api/0.x/Polygon.html), [maptalks.MultiPolygon](https://maptalks.org/maptalks.js/api/0.x/MultiPolygon.html) are supported.
