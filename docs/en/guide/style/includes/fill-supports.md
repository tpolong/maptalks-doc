* For vector tile data, Features with a type of Polygon or MultiPolygon are supported
* For GeoJSON data, Features with a type of Polygon or MultiPolygon are supported
* For vector layers, [maptalks.Polygon](https://maptalks.org/maptalks.js/api/0.x/Polygon.html), [maptalks.MultiPolygon](https://maptalks.org/maptalks.js/api/0.x/MultiPolygon.html) are supported.
